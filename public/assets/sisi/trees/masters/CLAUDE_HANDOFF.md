# SiSi Tree Assets — Claude handoff

이 ZIP의 `public` 폴더를 SiSi 프로젝트 루트에 병합하세요.
PNG 5개는 흰 배경과 나뭇가지 사이의 배경을 제거한 RGBA 이미지입니다.
Imagegen으로 배경을 제거했으므로 원본과 픽셀 단위로 동일하지 않으며 일부 잎 가장자리와 질감은 달라질 수 있습니다.
원본 업로드 순서와 파일의 매핑은 아래 표 및 manifest.json에 포함되어 있습니다.

| 업로드 순서 | 파일 | 추천 용도 |
| --- | --- | --- |
| 1 | tree-mid-01-tiered.png | 층이 나뉜 수관, 중간 거리 |
| 2 | tree-mid-02-curved.png | 휘어진 줄기, 중간 거리 |
| 3 | tree-mid-03-dense.png | 풍성한 수관, 중간 거리 |

## Claude에게 전달할 구현 요청

기존 Journey의 푸른 하늘, 구름, 길, 풀, 동반자를 유지하면서 첨부한 나무 에셋을 배치해줘.
먼 나무 → 중간 나무 → 길/동반자 → 가까운 풀과 양옆 나무 순으로 깊이를 구성해줘.
별과 말풍선 주변은 열어두고, 가운데 캐릭터와 하단 UI를 나무가 가리지 않게 해줘.
5개를 한 화면에 모두 표시하지 말고 스크롤하면서 자연스럽게 번갈아 나타나게 해줘.

- 모든 이미지의 비율을 유지해줘. CSS width를 정하고 height:auto를 사용해줘.
- 고정된 width와 height로 이미지를 늘이거나 object-fit:cover로 수관을 자르지 말아줘.
- world-layer 내부의 장식 요소로 구현하고 pointer-events:none, alt=""을 적용해줘.
- UI와 별의 터치 영역은 기존대로 유지해줘.
- 나무 밑동은 화면 하단이 아니라 각 레이어의 지면 기준선에 맞춰줘.
- 먼 나무는 작고 은은하게, 중간 나무는 뚜렷하게, 가까운 나무는 화면 양옆에 배치해줘.
- 불투명도를 일괄 낮추지 말고 실제 화면에서 먼 레이어에만 조정해줘.
- 가로 이동 속도는 먼 레이어가 가장 느리고 가까운 레이어가 가장 빠르게 해줘.
- CSS 변수를 이용해 작은 휴대폰에서도 길과 동반자 기준선이 유지되게 해줘.
- 배경 선택, 말풍선, 별, 하단 메뉴 등 기존 인터랙션을 확인해줘.

## 밑동 정렬

모든 PNG는 1089 × 1445px이며 투명 여백이 포함되어 있습니다.
`manifest.json`의 anchor는 이미지 전체 캔버스에서 계산한 밑동의 근사 좌표입니다.
anchor.x/anchor.y는 0~1이며 최종 화면 크기에서 눈으로 한 번 확인해주세요.

img의 position:absolute; left/top을 원하는 밑동 위치로 설정하고,
transform:translate(-anchor.x*100%, -anchor.y*100%)를 적용하면
투명 여백이 서로 달라도 밑동을 동일한 지면선에 맞출 수 있습니다.
transform-origin에도 같은 anchor 좌표를 사용하세요.
패럴랙스용 이동 transform은 부모 wrapper에 따로 적용하여 위 anchor 정렬을 덮어쓰지 마세요.

## 생성 및 검증

Built-in Imagegen / background-extraction으로 각 원본을 개별 처리했습니다.
공통 지시: 흰 종이 배경과 가지 사이의 빈 부분, 밑동 옆 수평 그림자만 제거하고,
원본 나무의 수관·줄기·가지·코발트 블루/청록 색·거친 붓질을 최대한 유지한 투명 PNG.
각 PNG의 RGBA 모드, 0~255 알파 범위, 파일 해독, ZIP 파일 목록을 검증했습니다.
이 패키지는 에셋과 구현 안내이며 실제 SiSi 코드에 적용되거나 배포되지는 않았습니다.
