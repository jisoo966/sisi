# SiSi — Butterfly Forest v2

사용자가 승인한 거칠고 단순한 미리보기를 기준으로 만든 낮 숲 테마 v2입니다. 잎과 꽃은 조금 삐뚤한 덩어리로, 나무는 넓은 색면과 끊긴 유화·크레용 붓결로 표현했습니다. 청록·블루그린·세이지를 중심으로 하고 크림색 햇빛은 포인트로 남겼습니다.

## 개별 레이어

| 파일 | 크기 | 용도 |
|---|---|---|
| forest-background | 1672×940 | 기존 하늘 대신 먼 숲 배경, 불투명 |
| forest-main-trees | 2048×768 | 새 큰 나무 레이어, 투명 |
| forest-tree-left / forest-tree-right | 각각 2048×768 | 좌우 나무를 개별 배치하는 권장 파일 |
| journey-walking-path-forest | 2048×768 | 기존 길 대신, 접지 기준 y=422 |
| journey-walking-ground-forest | 2048×768 | 기존 지면 대신, y=500부터 숲 바닥 |
| journey-midground-forest | 2048×768 | 기존 중경 식물 대신 |
| meadow-strip-forest | 2172×242 | 기존 meadow strip 대신 |
| forest-foreground | 2048×768 | 선택적 낮은 전경 |
| butterfly-ivory-01~03 | 각 256×192 | 크림색 나비의 세 가지 날개 자세 |

각 에셋은 png/와 webp/ 폴더에 있습니다. 여우는 기존 앱 캐릭터를 그대로 사용하며 배경에 합치지 않았습니다. 나비도 배경에서 분리했습니다.

## 큰 나무 배치

기존 작은 vegetation 레이어에 같은 렌더 크기로 넣으면 큰 나무도 작아집니다. forest-tree-left와 forest-tree-right를 각각 별도 레이어로 추가하는 배치를 권장합니다. y=638 뿌리를 앱의 --walking-baseline에 맞추고 상단의 잘린 수관이 화면 상단 또는 밖에서 시작하게 합니다. 430×936 정지 예시에서는 배율699/638, 나무 캔버스 표시 크기약2244×841px, y=0입니다. 왼쪽 나무의 소스 x≈350을 화면x=35로, 오른쪽 소스x≈1850을 화면x=395로 맞췄습니다. 따라서 각 레이어의 x는 rootScreenX - rootSourceX × scale입니다. 다른 기기는 CSS 변수로 계산하고 필요하면 나무를 화면 바깥쪽으로 이동하세요. 나무는 여우 뒤에 둡니다. forest-main-trees는 좌우가 함께 있는 원본 레이어이며 별도 큰 화면 합성에 사용할 수 있습니다. 모든 나무 파일 캔버스는2048×768입니다.

## 나비 애니메이션

나비 PNG는 정지 이미지이며 3장의 날개 자세를 포함합니다. 01 → 02 → 03 → 02를 약110ms 간격으로 반복하는 시작값을 제안합니다. 프레임 간 몸통 기준점을 정렬했습니다. 개체마다 타이밍을 달리하고 화면 표시 너비24~36px, 이동8~18 CSS px/s, 높이5~12px의 느린 오르내림을 적용하세요. 화면에는2~4마리, 이동 방향과 시작점을 다르게 두세요. butterfly-flutter-preview.gif는 날갯짓 확인용이며 앱 기능을 배포한 파일이 아닙니다. 고정된 자세를 쓰고 위치만 움직여도 됩니다.

## 미리보기와 적용

preview-concept.jpg는 사용자가 승인한 거칠고 단순한 스타일의 전체 콘셉트 그림입니다. preview-assets-horizontal.jpg와 preview-phone.jpg는 분리 에셋과 기존 여우를 합친 정지 조합입니다. preview-phone은 앞서 확인한 Journey의 길·지면·중경 배치를 기준으로 만들고 큰 나무만 별도 레이어로 추가했습니다. 구름은 울창한 숲 테마에서는 숨기는 방향입니다.

이 레이어들은 평면 원본 그림에서 픽셀 단위로 잘라낸 것이 아니라 같은 스타일을 참고해 각각 새로 그렸습니다. v1과 구분되는 새 파일 묶음입니다. 기존 에셋 크기를 맞췄으며 큰 나무와 나비의 레이어 연결이 추가로 필요합니다. 실제 사이트 코드는 변경하지 않았습니다. 연결 후 반복 스크롤 경계와 기기별 배치를 확인하세요.
